Keyboard shortcuts

EnterNew item (splits at the cursor)
Tab / Shift+TabIndent / outdent
Ctrl+Shift+↑ / ↓Move item up / down
Ctrl+↑ / ↓Collapse / expand
Ctrl+EnterMark complete
Ctrl+1 … Ctrl+6Color the line red, orange, yellow, green, blue, purple (again to remove)
Ctrl+0Remove color
Ctrl+Alt+1 … 3Heading 1 / 2 / 3 (again to remove; Ctrl+Alt+0 = normal)
Ctrl+B / Ctrl+IBold / italic (wraps the selection)
Ctrl+KInsert link (selected text becomes the link text)
Drag a bulletMove the item (long-press on touch). Drop it on a document in the sidebar to move it there.
Drag in sidebarReorder documents and folders, or drop them into a folder
Alt+→ / Alt+←Zoom in / out (or click a bullet)
Backspace at startJoin with the item above (deletes if empty)
Ctrl+Z / Ctrl+YUndo / redo
Ctrl+FSearch
Ctrl+SSync now (or tap the sync icon)
EscStop editing

Formatting: **bold**, __italic__, `code`, [text](https://…) links, and plain web addresses. On a phone, the Aa button has colors, headings, bold, italic and links.

Search looks in the current document; press All next to the search box to search every document.
