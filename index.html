Keyboard shortcuts

EnterNew item (splits at the cursor)
Tab / Shift+TabIndent / outdent
Ctrl+Shift+↑ / ↓Move item up / down
Ctrl+↑ / ↓Collapse / expand
Ctrl+EnterMark complete
Alt+1 … Alt+6Color the line red, orange, yellow, green, blue, purple (again to remove)
Alt+0Remove color
Drag a bulletMove the item (long-press on touch). Drop it on a document in the sidebar to move it there.
Alt+→ / Alt+←Zoom in / out (or click a bullet)
Backspace at startJoin with the item above (deletes if empty)
Ctrl+Z / Ctrl+YUndo / redo
Ctrl+FSearch
Ctrl+SSync now (or tap the sync icon)
EscStop editing

Formatting: **bold**, *italic*, `code`, links, and #tags (click a tag to search for it).
