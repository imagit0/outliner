Move to document

    Keyboard shortcuts

    EnterNew item (splits at the cursor)
    Tab / Shift+TabIndent / outdent
    Ctrl+Shift+↑ / ↓Move item up / down
    Ctrl+↑ / ↓Collapse / expand
    Ctrl+EnterMark complete
    Ctrl+1 … Ctrl+6Color the line red, orange, yellow, green, blue, purple (again to remove)
    Ctrl+0Remove color
    Ctrl+Alt+1 … 3Heading 1 / 2 / 3 (again to remove; Ctrl+Alt+0 = normal)
    Ctrl+B / Ctrl+IBold / italic (wraps the selection)
    Ctrl+H / Ctrl+THighlight / strikethrough
    Ctrl+KInsert link (selected text becomes the link text)
    Ctrl+.Expand / collapse
    Ctrl+Shift+BackspaceDelete item (with everything under it)
    Ctrl+Shift+MMove item to another document
    Ctrl+,Settings
    Ctrl+Alt+TInsert table
    In a table
    Tab / Shift+TabNext / previous cell (Tab in the last cell adds a row)
    EnterCell below (adds a row at the bottom)
    Ctrl+Alt+↑ ↓ ← →Insert row above / below, column left / right
    Ctrl+Shift+BackspaceDelete row
    Ctrl+Shift+0 … 6Color the whole row
    Drag a column edgeSet the column's width (double-click the edge for automatic width)
    Drag a bulletMove the item (long-press on touch). Drop it on a document in the sidebar to move it there.
    Drag in sidebarReorder documents and folders, or drop them into a folder
    Alt+→ / Alt+←Zoom in / out (or click a bullet)
    Backspace at startJoin with the item above (deletes if empty)
    Ctrl+Z / Ctrl+YUndo / redo
    Ctrl+FSearch
    Ctrl+SSync now (or tap the sync icon)
    EscStop editing

    Formatting: **bold**, __italic__, ~~strike~~, ==highlight==, `code`, [text](https://…) links and plain web addresses. Put ! in front of an image link — ![caption](https://…/pic.jpg) or !https://…/pic.jpg — to preview the image on hover (tap on a phone).

    On a phone, the Aa button has colors, headings, text styles, links, tables, move and delete.

    Search looks in the current document; press All next to the search box to search every document.

    Settings
