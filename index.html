    Keyboard shortcuts

    Editing
    New item (splits at the cursor)Enter
    Indent / outdentTab / Shift+Tab
    Join with the item above (deletes it if empty)Backspace at start
    Delete item (with everything under it)Ctrl+Shift+Backspace
    Mark completeCtrl+Enter
    Undo / redoCtrl+Z / Ctrl+Y
    Stop editingEsc
    Formatting
    Color the line red, orange, yellow, green, blue, purple (again to remove)Ctrl+1 … Ctrl+6
    Remove colorCtrl+0
    Heading 1 / 2 / 3 (again to remove)Ctrl+Alt+1 … 3
    Normal textCtrl+Alt+0
    Bold / italic (wraps the selection; they stack)Ctrl+B / Ctrl+I
    Highlight / strikethroughCtrl+H / Ctrl+T
    Insert link (selected text becomes the link text)Ctrl+K
    Show / hide formatting characters while editingCtrl+M
    Organizing
    Move item up / downCtrl+Shift+↑ / ↓
    Collapse / expandCtrl+↑ / ↓ or Ctrl+.
    Zoom in / out (or click a bullet)Alt+→ / Alt+←
    Move item to another document (goes to the top)Ctrl+Shift+M
    Move an item (drop it on a sidebar document to move it there)Drag its bullet
    long-press on touch
    Reorder documents and folders, or put them in a folderDrag in the sidebar
    Tables
    Insert tableCtrl+Alt+T
    Next / previous cell (Tab in the last cell adds a row)Tab / Shift+Tab
    Cell below (adds a row at the bottom)Enter
    Insert row above / below, column left / rightCtrl+Alt+↑ ↓ ← →
    Delete rowCtrl+Shift+Backspace
    Color the whole row (0 clears it)Ctrl+Shift+0 … 6
    or Ctrl+Alt+0 … 6
    Set a column's width (double-click the edge for automatic)Drag a column edge
    App
    Search (the All button searches every document)Ctrl+F
    Sync now (or tap the sync icon)Ctrl+S
    SettingsCtrl+,

    Formatting: **bold**, __italic__, ~~strike~~, ==highlight==, `code`, [text](https://…) links and plain web addresses. Put ! in front of an image link — ![caption](https://…/pic.jpg) or !https://…/pic.jpg — to preview the image on hover (tap on a phone).

    On a phone, the Aa button on the bottom toolbar has colors, headings, text styles, links and tables.
